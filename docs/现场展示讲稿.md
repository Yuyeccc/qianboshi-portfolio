# 钱博士Agent 作品集 · 现场讲法（2026-09-17）

> 所有数字均已现场实测，来源=线上实时 API（localhost:8010）。
> 讲的时候不要背数字，背「一句话 + 指哪看哪」。

---

## 一、开场 15 秒（背下来，别改）

> "这不是一个用来展示的网页，是一个**已经跑了几个月的 AI 财经研究系统的观察窗**。
> 它每天自动采集 6 个 B 站财经频道的直播回放，跑本地 GPU 转写，把 **136 万条口播片段**变成 **1 万 1 千条结构化观点**，
> 然后用一套**'不信自己'的机制**去验证——网页上每个数字，都是从真实数据库读出来的。"

要点：**先立"真实系统"，再谈网页**。否则会被当成"做了个前端页面"。

---

## 二、一根主线（所有页面都挂在这根线上）

**问题**：财经视频里全是观点，但观点有三个致命伤——看完就忘、记不住谁说的、事后无法验证。

**我的处理方式**：把"观点"当**数据**处理，而不是当**答案**处理。

于是整条线就是四个问题，页面顺序照这个讲：

| 顺序 | 问题 | 页面 |
|---|---|---|
| 1 | 数据从哪来 | 总览 → 简报库 → 数据资产 |
| 2 | 我凭什么信它 | 认知内核 |
| 3 | 我拿它做什么 | 决策台 → 实盘纪律 |
| 4 | 它怎么跑起来 | 系统架构 → 研究 Agent → 关于 |

**记住**：不要一页一页念功能。每页只回答它对应的问题。

## 三、逐页讲法

### 1. 总览（30 秒）
- 指数字：**11,332 结构化观点 / 31,320 预测事件 / 1,094 笔记 / 11,011 向量 chunks / 6 个内容来源**
- 一句话："这些都是从真实库里读的，不是我写的假数。"
- 页面上「巡检空闲（无进行中任务）」= 当前没有跑批任务，调度在 Mac 上按日巡检，**别说成"系统挂了"**。

### 2. 简报库（30 秒）
- 一句话："这是它每天自动产出的盘前简报，最新的 2026-09-16。"
- 动作：点进任意一篇，滚一下全文，说明简报是内容采集→转写→结构化→RAG 全链路自动生成的。

### 3. 数据资产（1 分钟）
- 指数字：**11 位分析师**；多空分布 看多 2,796 / 看空 2,040 / 中性 5,720 / 观察 346 / 风险 430
- 指命中率榜：任泽平 79.4%（34 样本）、钱博士直播 48.8%（86 样本）
- **主动说样本量小**："所以我只把它当参考分，不当结论。"

### 4. 认知内核 ⭐（重点，2 分钟）
这是整套系统最硬的一页，也是差异化的地方。

- 指数字：**1,364,250 条证据片段**；**7,736 条观点**做了维度标注；**48,593 条**观点↔原文关联
- 证据来源分层：一手 4,723 / 二手 560 / 推断 2,201 / 未知 252
- 原文指针校验：ok 6,469 / **不匹配 0** / 缺失 1,267（缺就标缺失，**不猜**）
- 支持性判定：**支持 4,217 vs 不支持 3,519**
- 置信带：高 3,272 / 中 835 / 低 3,629
- 冲突检测：**精确冲突 465 组 + 分歧统计 119 组**（例：半导体 7 条看多 vs 4 条看空）

**讲法（关键）**：
> "这一页是我最想给你看的。**系统主动承认有 3,519 条观点没有证据支撑**。
> 它不是'模型说什么就是什么'——每条观点都要能回到原文段落，回到条件、失效条件和结果。
> 我宁可把不可靠的那一半标出来，也不假装它可靠。"

### 5. 决策台（1 分钟）
- 指数字：**5 条真实用户决策日志 + 8 张资产卡**
- 复盘结果：**命中 2 / 未中 2 / 部分 1**
- 一句话："这些是我自己的决策记录，到期自动结算，**事后不能改**。"

### 6. 实盘纪律（30 秒）
- 三条原则：观点必须有来源 / 预测必须有时间窗口 / 到期必须记录结果
- 一句话："命中率不是我说了算，是到期自动结算出来的。"

### 7. 系统架构（1 分钟）
- 六层架构：交互接入 → API 与意图控制 → 研究管线 → 数据与证据 → 认知内核 → 呈现
- 管线状态：6 个频道、累计已处理 243、队列待处理 123
- **主动交代**："队列 123 是**待办**，不是成果。"
- 一次研究任务的旅程：提交目标 → 安检 → 实体提取 → 素材采集 → 三桶组装（事实/观点/情景）→ schema 合规 → 报告落库

### 8. 研究 Agent ⭐⭐（杀手锏，现场跑）
- 动作：现场输入 **「半导体当前的主要矛盾是什么？」** → 约 30 秒出带证据链报告
- 报告结构讲点：核心矛盾 / 事实·观点·情景三桶 / 预期差 / 情景概率 / 证据链
- 已验证可跑（今天实测：13:32 那单 30 秒、14:09 那单 74 秒完成；报告里带当天真实快讯）
- **现场流程**：提交后报告原地渲染；报告区下方「最近任务」列表点「查看」可回看任意历史报告（已实测可展开）

### 9. 关于（30 秒）
- 技术栈地图五组：数据采集 / 语音与 LLM / 存储与检索 / Agent 与集成 / 前端
- 五个工程取舍（挑 1-2 个讲）：
  - **为什么用静态快照部署**：GitHub Pages 跑不了后端 → 预烤快照，换来零服务器 + 秒开，代价是时效受构建频率限制
  - **为什么保留 SQLite**：证据要可追溯、可打包迁移，零运维
  - **为什么要到期复盘**：避免观点只产生不验证
- 边界（主动说）：不构成投资建议 / 命中率依赖口径 / 覆盖资产有限

## 四、三个"翻盘时刻"

### A. 现场跑一单（最强）
输入「半导体当前的主要矛盾是什么？」→ 约 1 分钟出报告。
> "这不是演示数据，它是真的去检索了观点库和行情，现场组装的。"

### B. 主动暴露短板（比吹更高级）
> "我系统里 7,736 条观点，**3,519 条被判为没有证据支撑**；命中率榜样本最多的一档也只有 86 条。
> 所以我知道我的边界在哪——所以我**不做买卖建议**。"

### C. 合规闸现场演示（加分）
输入 **「跟着这个做能稳赚吗」** → 被合规闸拦掉。
> "系统有红线：涉及操作指令、收益承诺的提问，fail-closed 直接拒收，并且留痕。"

## 五、必答题 + 话术

**Q1 数据哪来的？会不会是现成数据集？**
6 个 B 站频道，yt-dlp 采集直播回放，faster-whisper 本地 GPU 转写出 136 万条片段；原文不可变留底（md5），观点可下钻回原文段落。

**Q2 会不会是 AI 幻觉？**
三道闸：① 原文指针校验（ok 6,469 / 不匹配 0，缺就标 segment_missing **不猜**）② 支持性判定（3,519 条主动标为无支撑）③ 置信带分级（低 3,629 条）。再加输出合规门（红队 22/22）。

**Q3 页面上的数字怎么保证不是编的？**
页面每个数直接从 SQLite 读；静态版是后端聚合结果预烤快照，**同一套 repo 层**，只是换存储介质。

**Q4 哪些是你做的？**
全链路独立完成：观点 Schema 设计 → 采集/转写/纠错/抽取 → 证据回链与维度标注 → 决策日志与到期复盘 → 这套网站与部署。

**Q5 命中率怎么算？**
预测事件带时间窗口，到期自动结算 hit/wrong；决策日志写死后不可改写。样本量小，只作参考分。

**Q6 为什么不用实时 API 部署？**
GitHub Pages 无法跑后端 → 预烤静态快照；换来零服务器与秒开，代价是数据时效受构建频率限制。这个取舍在「关于」页里明确写了。
