## 第一步：查公网 IP（决定外网方案）

1. 路由器管理页（192.168.1.1 或看背面标签）→ 状态页 → 看 WAN 口 IP
2. 黑苹果终端执行 `curl ifconfig.me` 记下输出
3. 对比：
   - 路由器 WAN IP = ifconfig.me 输出 → **有公网 IP**（动态/固定再分）
   - WAN IP 是 100.64.x / 10.x / 172.16.x 开头 → **大内网 CGNAT**，无公网 IP
   - 两 IP 不一致 → 大内网

路线分支：
- 有公网 IP → 路由器端口映射 + DDNS + certbot HTTPS
- 无公网 IP → Cloudflare Tunnel（免费，免公网 IP，自带 HTTPS）

## 机器评估（结论：绰绰有余）

- FastAPI + ChromaDB + Nginx：i3 4 核够，8G 够（ChromaDB 1.1 万 chunks 约 1-2G）
- 256G 硬盘富余

## 部署目标架构

```
黑苹果服务器（家，7x24）
  ├─ FastAPI 后端（uvicorn 8010，launchd 守护：开机自启+崩溃重启）
  ├─ 数据：qianboshi-agent 全部数据（SQLite + JSONL + ChromaDB 向量库整体拷，勿重建）
  ├─ 前端：npm run build（API 模式）→ Nginx 托管 + 反代 /api → 8010
  ├─ 域名 + HTTPS（免费证书）
  └─ 外网：公网 IP 直连 或 Cloudflare Tunnel
```

## 分阶段步骤

### 阶段 0：黑苹果环境准备（半天）
- 确认 macOS 版本、开 SSH（系统设置→通用→共享→远程登录）
- Homebrew → Python 3.12+ → git
- 测 `curl ifconfig.me` 确认公网情况

### 阶段 1：数据+代码上机（半天）
- E:\qianboshi-agent 代码和数据拷到黑苹果（网络共享/U盘）
- **ChromaDB 向量库整体拷，不重建**（1.1 万 chunks 重建很贵）

### 阶段 2：后端跑起来（半天）
- venv + 装依赖（fastapi/uvicorn/chromadb；**转写/whisper 依赖可省**——展示机只跑 API）
- uvicorn 8010 验证 `curl localhost:8010/api/v1/overview`
- launchd 配守护

### 阶段 3：前端 + Nginx（半天）
- 前端 build（API 模式连黑苹果后端）
- Nginx 托管 dist + 反代 /api → 8010
- 本地 curl 全链路验证

### 阶段 4：外网 + HTTPS（半天）
- 公网 IP：路由器映射 443/80 + DDNS + certbot
- 无公网：cloudflared 隧道 + 域名（qianboshi.top 一年十几块）
- Cloudflare 托管 DNS

### 阶段 5：数据同步（后续维护）
- Windows 本地是"生产机"（采集/转写/日报），黑苹果是"展示机"
- 同步：本地跑完 → 脚本 scp/rsync 增量推送到黑苹果 → 线上实时更新
